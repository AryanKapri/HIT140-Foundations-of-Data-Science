**FIFA World Cup 2026 — Data Science Project** 

This project uses Python and Linear Regression to analyse football match data and predict match outcomes.

**Objective 2.1:** Predict the goal difference between two opposing teams using 104 match records and eight pre-match explanatory variables.

**Objective 2.2:** Predict the number of goals scored by an individual team using 208 team-match records and eight pre-match explanatory variables.

**Libraries:** Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn.

**Evaluation:** R² Score, Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE).
